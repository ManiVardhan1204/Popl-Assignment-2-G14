\# P2 prompts (word for word)



\## Prompt 1

using prolog-dev: for P2, write split(List, Left, Right) which splits a list into two non-empty parts, Left followed by Right gives List, keeping the order. it should give every possible split on backtracking.



\## Prompt 2

using prolog-dev: for P2, write expr(Nums, Tree, Value). it builds every expression tree over the numbers in Nums in the same order (each number used once, no joining digits, no unary minus) using + - \* /, and computes its integer Value while building. trees are like plus(L,R), minus(L,R), times(L,R), divide(L,R), or a plain number. division only allowed if the divisor is not 0 and it divides exactly, checked at every node. no string parsing.



\## Prompt 3

using prolog-dev: for P2, write tree\_string(Tree, String) that turns an expr tree into an SWI string with no spaces using these rules: \* and / bind tighter than + and -. operators are left associative. a left operand gets brackets only if its top operator has lower precedence than the parent. a right operand gets brackets if its top operator has the same or lower precedence than the parent. a single number never gets brackets. examples: (4+2)\*3, 4+2\*3, 8/4\*2, 8/(4\*2), 1-2-3, 1-(2-3), 1+(2+3), 1+2+3.



\## Prompt 4

using prolog-dev: for P2, write generate\_equation(List, Equation) using split, expr and tree\_string. Equation is a string "L=R" where both sides have the same value. it should fail (not loop or error) if there's no valid equation, including lists of length 0 or 1. then write all\_equations(List, Equations) with findall and sort/2 to remove duplicates, and count\_equations(List, N).



\## Prompt 5

using prolog-dev: write a test file for P2 in tests/ that loads ../code/G12\_q2.pl and prints PASS or FAIL for each check: all\_equations for \[4,2,5,3], \[2,4,8] and \[2,3,4] match the examples, count\_equations \[4,2,5,3] is 7, generate\_equation fails for \[2,3,4], \[] and \[5], generate\_equation \[4,2,5,3] gives one of the 7, the 8 bracket examples from tree\_string, division by zero and non-exact division are skipped, and the output is a string not an atom.
