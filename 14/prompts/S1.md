\# S1 prompts (word for word)



\## Prompt 1

using scheme-dev: for S1, a tree is () or (value left right). write inorder, preorder and postorder that return the list of values. use an accumulator so no append or reverse is needed.



\## Prompt 2

using scheme-dev: for S1, write height and leaf-count. height of () is 0, a node is 1 + the max of its subtree heights. a leaf is a node with both subtrees empty, the empty tree has 0 leaves.



\## Prompt 3

using scheme-dev: for S1, write print-inorder (prints the inorder list on one line), print-all-traversals (prints inorder, preorder, postorder lists on 3 lines) and print-height-and-leaves (prints the list (height leaf-count) on one line). use display and newline, every function ends with a newline.



\## Prompt 4

using scheme-dev: write a test file for S1 in tests/ that checks the exact printed output of all 3 print functions for t1, t2, t3 and the empty tree from the assignment, plus a symbol tree and a single node. print PASS or FAIL for each.
